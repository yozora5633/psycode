PsyCode プライバシーポリシー

最終更新日: 2026年10月6日

1. 基本方針

1.　開発者は，PsyCode（以下「本アプリ」という．）の利用に関して，利用者の個人情報を直接収集しない．Android 版の翻訳 SDK による取扱いは第4節及び第5節による．

2.　本アプリは，利用者の行動を追跡せず，広告を表示せず，広告識別子を利用せず，広告のための解析基盤を組み込んでいない．Android 版の ML Kit は第4節の情報を Google に送信する．

3.　開発者は，本アプリのためのサーバーを有しない．分類のデータはアプリに同梱されており，本アプリは，これを読むために通信を行わない．

4.　本アプリの利用に，利用者の登録又はアカウントを要しない．

5.　前各項にかかわらず，利用者が OS（iOS 又は Android）との診断情報の共有を有効にしている場合，開発者は，Apple 又は Google を通じて，個人を特定しない範囲の障害情報（クラッシュログ）を受け取ることがある．

2. 開発者が収集しない情報

開発者は，次の各号に掲げる情報を含め，利用者に関する情報を直接収集しない．この規定は，Android 版の ML Kit による第4節の送信を否定するものではない．

一　氏名，住所，電話番号，メールアドレスその他の連絡先

二　検索した語及び閲覧した項目

三　お気に入りに入れた項目

四　位置情報

五　広告識別子その他の端末識別子

六　利用状況の統計又は解析情報

3. 端末内に保存される情報

1.　本アプリは，次の各号に掲げる情報を利用者の端末内に保存する．

一　お気に入りに入れた項目の識別子及びグループ

二　閲覧履歴及び最後に読んでいた節の位置

三　初回の説明を表示したかどうかの記録

四　利用者の操作により作成した訳文（設定で件数及び容量を確認し，削除することができる．）

五　表示及び操作に関する設定

2.　開発者は，前項の情報を取得することも閲覧することもできない．

3.　本アプリを削除すると，第1項の情報は当該端末から削除される．

4.　Android 版は，クラウドへのバックアップを行わない設定としている．機種変更の際は，OS が対応する端末間の直接移行に限り，お気に入り，グループ，閲覧履歴，初回説明の完了の記録及び設定を引き継ぐことができる．Android 9 以上で，利用する端末が当該移行に対応していることを要する．Android 8.0 及び 8.1 では引き継がない．作成した訳文，言語データ及び翻訳の同意の記録は，クラウドへのバックアップ及び端末間の移行のいずれにも含めない．

4. 外部への送信

1.　iOS 版は，利用者に関する情報を開発者又は外部の事業者へ送信しない．Android 版は INTERNET 権限を持ち，翻訳の言語データの取得並びに ML Kit の利用状況の送信及びこれらに伴う SDK の設定通信だけに用いる．本文及び訳文は Google を含む外部の事業者へ送信しない．端末間の直接移行は，第3節第4項による．

2.　利用者が本アプリの中のリンクを開いた場合に限り，端末のブラウザで外部のサイト（WHO の ICD-11 閲覧サイト，米国精神医学会の公開資料，厚生労働省の統計分類のページ等）が表示される．表示した後の取扱いは，そのサイトの運営者の方針による．

3.　本アプリは，患者に関する情報を入力する欄を設けていない．

4.　Android 版の ML Kit は，端末の製造元・機種・OS・ハードウェア，アプリのパッケージ名・版，インストールごとの識別子，処理時間，API 設定，入出力の大きさ，機能の版，イベントの種類，エラーコード及び翻訳元・翻訳先の言語を，診断及び利用状況の分析のため Google に送信する．SDK が用いる Firebase Installations のインストール識別子及び user agent，Remote Config の国・言語コード，タイムゾーン，OS・プラットフォーム・SDK の版及びアプリ識別情報も，設定並びにサービスの提供・維持・改善に用いられる．本文及び訳文の内容は含まれない．

5.　前項の通信は HTTPS で暗号化される．ML Kit は当該情報を第三者へ移転しないとし，Firebase はサービスの再委託先等を例外とする．詳細は，ML Kit のデータ開示，利用規約とプライバシー及びFirebase のデータ開示による．

6.　初回の翻訳の同意前は，SDK の初期化及び言語データの状態照会を行わない．設定の表示及び確認のキャンセルでは，同 SDK による通信を開始しない．同意後は SDK が利用状況等を自動送信し，これを個別に停止する設定はない．同意の記録は当該端末だけに保存する．

5. 端末の機能の利用

1.　本アプリは，カメラ，マイク，写真，位置情報，連絡先その他の端末の機能を利用しない．

2.　前項にかかわらず，本アプリは，利用者が操作した場合に限り，OS の読み上げ機能及び端末内の翻訳機能を利用する．翻訳は端末内で行われ，本文を開発者又は外部の翻訳サーバーへ送信しない．

3.　iOS 版は，iOS の翻訳機能を利用する．端末に当該言語のデータが無い場合において，OS がアップル社からそのデータを取得することがある．

4.　Android 版の翻訳は，Android 8.0 以上で Google Translate による ML Kit の端末内翻訳を利用する．初回は取得先（Google），容量（約30 MB）及び本文を送信しない旨を示し，同意した後に言語データを取得する．取得後は通信なしで翻訳できる．本文及び訳文を Google に送信しない．

5.　言語データは設定の「翻訳」で取得済みかを確認し，「言語データを消す」から削除できる．取得中は「取得を中止して言語データを消す」を利用できる．保存した訳文は別に「保存した訳文を消す」から削除する．言語データを消した後，新たに訳す場合は再度確認して取得する．これらの操作は，Google に送信済みの利用状況を削除するものではない．

6. 第三者への提供

開発者が直接取得して第三者へ提供する情報はない．Android 版の Google への送信及び Firebase の再委託先等の取扱いは，第4節による．

7. 広告

本アプリに広告は含まれていない．アプリ内の課金も行わない．

8. 言語

本方針は日本語を正文とする．他の言語に翻訳して提供する場合において，日本語版と他の言語版との間に相違があるときは，日本語版の解釈が優先する．

9. 本方針の変更

開発者は，本方針の内容を変更することがある．変更した場合は，本ページを更新し，最終更新日を改める．
